# AI-Based Water Demand Forecasting System

This project predicts water demand using Artificial Intelligence and provides intelligent recommendations using Retrieval-Augmented Generation (RAG).

## Problem
Manual water planning leads to water wastage, power loss, or shortages due to lack of forecasting.

## Solution
- Machine Learning predicts future water demand
- RAG logic retrieves historical data and generates pump scheduling recommendations
- Streamlit dashboard visualizes insights

## Technologies Used
- Machine Learning (Linear Regression)
- Retrieval-Augmented Generation (RAG)
- Python
- Streamlit

## How to Run
```bash
pip install -r requirements.txt
python train_model.py
streamlit run app.py
